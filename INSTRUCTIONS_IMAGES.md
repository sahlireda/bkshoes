# Instructions pour ajouter les images des mocassins

## 📸 Images à ajouter

Vous avez fourni 4 magnifiques images de mocassins. Voici comment les ajouter à votre site :

### Étapes à suivre :

1. **Renommez vos images** selon ces noms :
   - Image 1 (mocassins beiges/camel avec détail métallique) → `mocassin-camel.jpg`
   - Image 2 (mocassins blancs élégants) → `mocassin-blanc.jpg`
   - Image 3 (mocassins noirs avec détail métallique) → `mocassin-noir.jpg`
   - Image 4 (mocassins beiges/taupe avec boucle) → `mocassin-taupe.jpg`

2. **Copiez les images** dans le dossier `images/` de votre site :
   ```
   Bkshoes/
   ├── images/
   │   ├── mocassin-camel.jpg
   │   ├── mocassin-blanc.jpg
   │   ├── mocassin-noir.jpg
   │   └── mocassin-taupe.jpg
   ├── index.html
   ├── styles.css
   └── ...
   ```

3. **Les images sont déjà configurées** dans le code HTML :
   - ✅ Mocassins Cuir Camel → `images/mocassin-camel.jpg`
   - ✅ Mocassins Noirs Vernis → `images/mocassin-noir.jpg`
   - ✅ Mocassins Blancs Été → `images/mocassin-blanc.jpg`

## 🎨 Correspondance Images/Produits

| Produit sur le site | Image à utiliser | Description |
|---------------------|------------------|-------------|
| **Mocassins Cuir Camel** | `mocassin-camel.jpg` | Mocassins beiges avec détail métallique |
| **Mocassins Noirs Vernis** | `mocassin-noir.jpg` | Mocassins noirs avec détail métallique |
| **Mocassins Blancs Été** | `mocassin-blanc.jpg` | Mocassins blancs élégants |

## 📱 Résultat

Une fois les images ajoutées :
- ✅ Les placeholders seront remplacés par vos vraies images
- ✅ Effet hover avec zoom léger sur les images
- ✅ Images optimisées pour tous les écrans (responsive)
- ✅ Chargement rapide avec `object-fit: cover`

## 🚀 Déploiement

Après avoir ajouté les images :
1. Testez localement en ouvrant `index.html`
2. Déployez sur Netlify en glissant-déposant tout le dossier
3. Vos clients verront les vraies images de vos mocassins !

---

**Note :** Si vous voulez ajouter la 4ème image (mocassin-taupe.jpg), vous pouvez créer un 4ème produit ou remplacer l'un des existants dans le code HTML.
